# Изменения

## NSP07 — бой гостя, возрождение и утечки мобов

- Исправлен выбор цели удара на клиенте: исходная хит-зона моба используется без дублирующего физического тела, добавлен запасной поиск сетевой цели для промахивающегося луча. Стены по-прежнему ограничивают выбор цели.
- Проверяется подтверждение урона хостом, повторные удары и смерть. Копии мобов на клиенте не наносят повторный локальный урон через свои анимационные события.
- Поднятие возвращает половину здоровья на безопасной точке падения. Отдельно доступны возврат к напарнику и на точку возрождения; управление не включается до загрузки пола. Повторное подтверждение поднятия уже живого игрока игнорируется.
- Варианты моделей, цвета и блок мимика передаются всем гостям. Подготовленное визуальное состояние переиспользуется для каждого получателя, а не только для первого клиента.
- Убрано двойное обновление AnimationTree; отдельная анимация смерти не переводится в ручной режим по ошибке. Фаза процедурной анимации не сбрасывается к старому пакету каждый кадр.
- Настройка физики моба выполняется один раз. Создание клиентских мобов распределено по кадрам, область интереса согласована с дальностью мира, статические цвета не обновляются без изменения.
- У мимиков и Hwobbb удалены осиротевшие отладочные сферы, создававшиеся для каждой ноги. Воспроизведённый аварийный выход с мимиком после исправления завершился с кодом 0; число осиротевших узлов — 0 → 0.
- Таймеры очистки снарядов используют слабые ссылки; в журнал добавлены редкие замеры `[nx-net]`.
- Протокол LBNX5: обновить все консоли. Изменение FPS на Switch ещё требует аппаратного сравнения.

## NSP06 — до четырёх игроков и исправление вылета при подключении

- По отчётам NSP05 исправлен нулевой указатель в `World::get_block_type_at`: таймер обращался к чанку после его выгрузки. Чтение отсутствующих блоков, воды и огня теперь безопасно; запись в отсутствующий чанк пропускается.
- Хост и три гостя по LAN. В поиске учитываются четыре места; полная комната не выбирается для подключения.
- Загрузка областей учитывает до четырёх центров. Перекрывающиеся области используют общий пул чанков; очередность генерации чередуется между игроками.
- Существа на хосте обрабатываются в загруженной области рядом с игроками. Полный пересмотр их активности выполняется пять раз в секунду, без повторной настройки каждого существа на каждом проходе.
- Убраны лишние полные обновления удалённых персонажей при каждом клиентском пакете. Регулярные позы передаются без надёжной очереди, события действий — надёжно. Убран частый вывод действий в лог.
- Снимки мира передаются с упакованными бинарными массивами вместо JSON-списков. Отправка порционная, несколько подключений обслуживаются последовательно. Формат сохранений на карте не менялся.
- Протокол LBNX4: всем участникам нужен NSP06. Проверены четыре процесса игры, общий спавн, блоки, вид персонажей и выход клиентов. Прогон четырёх Switch и улучшение FPS на устройстве пока не подтверждены.

## NSP05 — рука и предметы другого игрока

- Исправлена отсутствующая привязка меша персонажа к скелету.
- Предметы в руке используют оригинальные меши, текстуры и цвета; блоки — текстуры всех граней.
- Передаются цвет кожи, ведущая рука, взгляд и события действий оригинальной руки. Позы удалённой руки учитывают тип предмета.
- Хост после загрузки мира сразу играет, без принудительного экрана ожидания.
- Исправлена проверка подключённых игроков на хосте. Протокол LBNX3 требует обновить обе консоли.
- Проверены 848 предметов (включая 302 кубических блока), привязка скелета и обмен действиями в двух процессах игры. Прогон на консолях ещё нужен.

## NSP04 — автоматический LAN

- Новый экран: создать комнату, найти игру, вернуться. IP и порт убраны из основного интерфейса.
- Создание комнаты из главного меню: выбор мира, автоматический запуск хоста после загрузки.
- Клиент сам находит адрес хоста и подключается. Объявления комнат, запросы по IPv4 и ограниченный запасной обход локальных адресов.
- Убран запуск клиента на собственный адрес 127.0.0.1; обнаруженный адрес передаётся напрямую, без подмены скрытыми полями старого меню.
- Проверены нормальный поиск и поиск с отключённым broadcast, общий спавн, блоки в обе стороны, выход гостя. Проверено размещение элементов меню с длинными названиями миров и русским языком.


## NSP03 / OPT06 — локальный тест

- Профиль 75% / 32 блока / минимальные эффекты, громкость 75/75. Пресеты больше не стирают язык и звук.
- Кеш подготовки областей мира; ограниченные обновления мешей; вода в перекрытии областей двух игроков рассчитывается один раз.
- Штатный CPU FastLoad на загрузке с возвратом в обычный режим. Рабочие потоки используют разрешённые процессу ядра вместо жёсткой маски трёх ядер.
- Двухместный LAN-кооператив: вход из меню, поиск хостов, ручной IP, общий мир и отдельный кеш гостя. Сетевые действия используют игровые назначения кнопок.
- Сохранена игровая логика версии 5.2; добавлены модель удалённого игрока и анимации.
- На ПК проверены общий спавн и двустороннее изменение блоков двумя настоящими игровыми процессами. Проверка LAN и производительности на двух Switch ещё нужна.

## NSP02 / OPT05 — локальный тест

- Ровные участки поверхности воды одинаковой высоты объединяются в прямоугольники. Для плоского участка 16×16 требуется один прямоугольник вместо 256; границы и частичные уровни воды сохранены.
- На Switch обновляется не более одного водного меша за отображаемый кадр. Очередь обходит чанки по кругу, включая первоначальное создание поверхности.
- Добавлены отдельные замеры времени симуляции и обновления воды: `[nx-water]` в журнале.
- В настройках появился выбор English/Русский. Английский остаётся языком первого запуска; выбор сохраняется вместе с настройками, отмена возвращает сохранённый язык.
- Русский словарь содержит 797 строк меню, предметов, характеристик и сообщений. Добавлен шрифт для кириллицы; внутренние идентификаторы предметов не меняются.
- Проверка текстуры при старте читает изображение один раз вместо трёх.

На ПК проверены геометрия воды, переключение и сохранение языка в игровом меню, контрольные суммы ресурсов. Производительность и запуск NSP02 на Switch ещё требуют прогона. LAN-кооператив в этот пакет не включён.

## OPT01–OPT04 — внутренние сборки

Ограничены дальность и очередь мешей, освобождаются временные буферы геометрии. Отключены проблемные локальные тени, сокращён обход симуляции воды и огня. Добавлены облегчённые материалы, интеграция SaltyNX, кеш мешей и замеры этапов загрузки.
