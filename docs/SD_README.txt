Lucid Blocks NX — NSP07 / COMBAT AND REVIVE
Адаптация для Nintendo Switch: Dimasick-git.

Установка
Установить LUCID_BLOCKS_NX_FULL_NSP07.nsp через DBI на всех консолях.
Запускать с HOME. Внутри NSP находятся движок, игра и кеш предметов;
распаковка ресурсов на карту не нужна. Для обновления установленной игры
нужно установить новый NSP: старый использует собственные ресурсы.

Запасной вариант — lucid-blocks.nro через hbmenu в режиме приложения
с полной памятью. Режим альбома не подходит.

LAN: автоматически, от двух до четырёх игроков
На всех консолях установить один и тот же NSP07 и включить одну сеть Wi-Fi.
Хост: главное меню → LAN Co-op → «Создать комнату» → выбрать или создать мир.
После загрузки мира комната откроется сама. Создать комнату также можно из паузы.
Друг: главное меню → LAN Co-op → «Найти игру». Игра сама найдёт адрес и подключится.
Вводить IP, порт или код не нужно. Хост сразу играет, без экрана ожидания друга.
Если широковещательные пакеты не проходят, включается обход локальных адресов.
Поиск работает только при открытом сетевом меню; вне него лишнего опроса нет.
Сохранение мира остаётся у хоста, для гостя используется отдельный сетевой кеш.
Первое появление гостя — рядом с хостом. Предыдущие NSP используют прежний протокол:
для совместной игры обновить обе консоли. Это LAN, не интернет-комнаты.

Другой игрок: исправлены привязка скелета, рука с предметом, цвета блоков и кожи,
наклон взгляда и позы действий. Собственный вид от первого лица сохранён.

NSP07: исправлены удары гостя, передача внешности мобов всем участникам,
поднятие с половиной здоровья, ожидание пола перед возрождением и утечки
невидимых узлов у мимиков и Hwobbb. На экране падения действие «Прыжок» —
возврат к напарнику; «Взаимодействие» — на спавн. Другой игрок может поднять на месте.
В лог добавлены замеры [nx-net] для проверки оставшихся рывков.

Начальные параметры
Рендер 75%, дальность 32 блока, минимум эффектов, без дизеринга, лимит 60 FPS.
Общая громкость — максимум: 75/75 по шкале оригинальной игры.
Минимальный профиль применяется однократно; затем настройки сохраняются.
Язык по умолчанию English. Русский выбирается в настройках экрана и сохраняется.
A — подтверждение; B — назад; правый стик управляет курсором меню.

Производительность
Кеш подготовки чанков сокращает повторные обходы мира. Обновления водных мешей
распределены по кадрам. Области до четырёх игроков загружаются отдельно, общая вода
не рассчитывается дважды. На загрузке запрашивается штатный CPU FastLoad,
после загрузки или потери фокуса запрос снимается. Число рабочих потоков
выбирается по разрешённой маске ядер процесса: четвёртое ядро используется,
только если доступно системе. Системные модули и частоты не патчатся.
Поддержка SaltyNX сохранена. Стабильные 60 FPS на всех сценах не подтверждены.

Данные на карте
Сохранения: /switch/lucid-blocks/LucidBlocksNX/
Журнал: /switch/lucid-blocks/boot.log
Графический кеш: /switch/lucid-blocks/cache/
Не удалять личные сохранения при обновлении.

Для проверки: одинаковый NSP на обеих консолях, совместная установка/разрушение
блоков, уход от хоста, смерть, выход гостя и повторный вход. Сравнить тот же
участок у воды без разгона. После прогона сохранить boot.log с обеих карт.

Оригинальная игра принадлежит разработчикам Lucid Blocks.
Авторы компонентов и модели игрока перечислены в CREDITS.md и NxPort/coop_mod/ATTRIBUTION.json.
