# Lucid Blocks NX — NSP07

Исправления боя и возрождения в кооперативе, передачи внешности мобов и утечки ресурсов. Цельный `LUCID_BLOCKS_NX_FULL_NSP07.nsp` для DBI.

## Исправления

- Гость может выбрать сетевого моба для удара. Проверяются повторные попадания, уменьшение здоровья на хосте и смерть; лишняя копия хит-зоны убрана.
- Поднятие — с половиной здоровья в месте падения, если точка безопасна. Возврат к напарнику и на спавн выполняются отдельно, с ожиданием загруженного пола. На экране падения: действие «Прыжок» — к напарнику, «Взаимодействие» — на спавн.
- Варианты моделей, цвета и блок мимика получают все гости. Локальные копии мобов не должны повторно выполнять авторитетный урон хоста.
- Исправлены двойное обновление анимаций, сброс процедурной фазы и ошибочный выбор проигрывателя анимации смерти.
- Убрана повторная настройка коллизий на каждом снимке. Появление мобов распределено по кадрам; область сетевого интереса ограничена дальностью мира.
- Удалены неиспользуемые 3D-сферы, которые утекали при каждом появлении мимика и Hwobbb. Отдельный тест мимика перестал аварийно завершаться при выходе.
- Исправлены таймеры, ссылавшиеся на удалённые снаряды. `[nx-net]` в логе показывает затраты обработки снимков и создания мобов.

## Установка

Установить NSP07 через DBI **на всех консолях**, затем запускать с HOME. Одного копирования на карту недостаточно для обновления установленной игры.

LAN: 2–4 Switch в одной сети Wi-Fi. Хост выбирает **LAN Co-op → Создать комнату**, затем мир. Остальные выбирают **Найти игру**. NSP06 использует другой протокол и с этой сборкой не соединяется.

Не удаляйте `/switch/lucid-blocks/LucidBlocksNX/`: там сохранения и настройки.

## Статус

Это prerelease. Бой, поднятие, варианты возрождения и передача внешности проверяются в настоящих процессах игры на ПК. Исправлена воспроизводимая утечка и авария при выходе с мимиком. Новый запуск и FPS на Switch ещё нужно проверить: стабильные 60 кадров не заявляются.

После прогона полезны `boot.log` с обеих карт, участок с просадкой и свежий crash report, если игра закрылась.
