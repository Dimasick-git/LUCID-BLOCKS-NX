# Lucid Blocks NX — NSP06

LAN-кооператив для 2–4 игроков и исправления после отчётов NSP05. Один установщик для DBI: `LUCID_BLOCKS_NX_FULL_NSP06.nsp`, **881 МБ**. Отдельный пакет ресурсов не нужен.

## Что изменилось

- Исправлен обнаруженный в crash reports доступ к выгруженному чанку. Таймер мог запросить блок после выгрузки области и закрыть игру. Аналогичные обращения к воде и огню тоже защищены.
- Хост и три гостя: поиск учитывает четыре места. Области всех игроков участвуют в загрузке; перекрывающиеся чанки не выделяются повторно для каждого участника.
- Уменьшена лишняя работа хоста: обработка существ ограничена загруженными областями рядом с игроками, реже перестраиваются настройки их активности и удалённых персонажей.
- Позы больше не накапливаются в надёжной сетевой очереди. События действий остаются надёжными; частая запись каждого действия в лог убрана.
- Снимок мира передаётся бинарными массивами и порциями. Несколько подключений обслуживаются по очереди. Формат личных сохранений на карте не менялся.
- Сохранены автоматический поиск без IP, общий спавн, русские настройки, вид руки и предметов напарника, SaltyNX и профиль 75% / 32 блока.

## Установка и LAN

Установите NSP06 через DBI **на всех консолях**, затем запускайте с HOME. NSP05 и более ранние сборки используют другой сетевой протокол.

Подключите Switch к одному роутеру. Хост: **LAN Co-op → Создать комнату → выбрать мир**. Гости: **LAN Co-op → Найти игру**. Хост сразу играет; адрес вводить не нужно. Интернет-комнаты в этой версии не реализованы.

Сохраняйте `/switch/lucid-blocks/LucidBlocksNX/` при обновлении. Журнал игры — `/switch/lucid-blocks/boot.log`.

## Проверки и ограничения

Проверены четыре настоящих процесса игры на ПК: автоматическое подключение, поиск без broadcast, общий спавн, передача блоков, предметов и действий, выход трёх гостей. ARM64-компоненты собраны; NCA, RomFS/IVFC и содержимое установщика проверены повторным чтением.

Это **prerelease**. Исправление вылета проверено по коду и отчётам; новый аппаратный прогон ещё нужен. Проверка четырёх процессов на ПК не заменяет тест четырёх Switch. Улучшение FPS на устройстве и стабильные 60 кадров не подтверждены. При повторном вылете приложите свежие `boot.log` и отчёт из `atmosphere/crash_reports`.
