# v0.1.0 / NSP07: статус проверки

| Проверка | Результат |
| --- | --- |
| ARM64/Horizon runtime | Собран, double precision |
| Статический gdblocks и исправление TLS | Сохранены из рабочих внутренних сборок |
| Сжатый PCK | 815 МБ, ресурсы прочитаны блочно из установленного NSP |
| Распакованные данные ресурсов | Контрольные суммы входного пакета совпали |
| Чтение блоков в Godot на ПК | Полное чтение крупных текстур и переходы через границу 256 КиБ прошли |
| Готовые меши | 321 ресурс загружен в Godot |
| LAN | Хост и три клиента проверены на ПК; общий спавн, блоки, предметы, действия и внешность синхронизируются |
| Combat/revive | Урон хостом, повторные удары, смерть, поднятие и возврат проверены на ПК |
| NSP, NCA, RomFS/IVFC | Проверены повторным чтением установщика |
| Иконка, название, автор и версия | Проверены внутри Control NCA |
| FPS на стоковых настройках | Примерно 30–40 FPS |
| FPS на системе с разгоном | 60+ FPS |
| Установка и запуск полного NSP на Switch | Рабочий релизный прогон зависит от конкретной консоли и конфигурации |

Это экспериментальный релиз. Производительность зависит от сцены, состояния мира, сетевой активности и профиля системы; стабильные 60 FPS без разгона не гарантируются.
