# Установка NSP07

1. Скачай `LUCID_BLOCKS_NX_FULL_NSP07.nsp` со страницы prerelease.
2. Установи файл через DBI. При передаче по USB/MTP выполняй установку в DBI, затем закрой установщик.
3. Запускай Lucid Blocks NX с HOME. Запуск через альбом не подходит из-за ограниченной памяти.

Полный NSP использует тот же Title ID `0100963461C50000`, что и прежний форвардер. Он содержит NRO, сжатый пакет и готовые меши. Загружать отдельный `game.pck` для этой установки не нужно.

## Обновление старой установки

Не удаляй `/switch/lucid-blocks/LucidBlocksNX/`: там находятся сохранения, настройки и записываемый кеш. После успешного запуска полного NSP прежние `/switch/lucid-blocks/game.pck` и `/switch/lucid-blocks/lucid-blocks.nro` можно убрать с карты. Папку `lucid-blocks` целиком удалять нельзя.

Для проверки источника ресурсов открой `/switch/lucid-blocks/boot.log`: строка загрузки полного NSP должна указывать `title:/lucid-blocks/game.pck`.

## Проверка prerelease

Для LAN установи NSP07 на все 2–4 консоли и подключи их к одному роутеру. На хосте выбери **LAN Co-op → Создать комнату**, затем мир. На гостях выбери **Найти игру**. Адрес находится автоматически. Сборки до NSP07 несовместимы с новым сетевым протоколом.

Повтори один и тот же участок без разгона: загрузка мира, вода, перемещение через границы чанков, сохранение и повторный запуск. При проблеме приложи `boot.log`, название сборки, модель консоли и место сбоя. При вылете также нужен свежий отчёт из `atmosphere/crash_reports`.

SaltyNX необязателен для запуска. На настроенной системе игра публикует показания FPS в его общую память. Этот NSP не заменяет системные модули и не включает разгон.
