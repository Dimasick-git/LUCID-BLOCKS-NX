# Проверка NSP02 / OPT05

Это локальная тестовая сборка. Она содержит оптимизацию воды и русский перевод; сетевой режим пока не готов.

Установить `LUCID_BLOCKS_NX_FULL_NSP02.nsp` через DBI на каждой консоли и запустить с HOME. Установка заменяет приложение с тем же Title ID. Сохранения и выбранные параметры на карте остаются прежними.

В настройках на вкладке экрана доступен выбор языка. Чтобы оставить русский после перезапуска, выбрать «Русский» и сохранить изменения. Возврат без сохранения отменяет предварительный выбор.

Для сравнения производительности пройти тот же участок у воды с теми же настройками и частотами. Полезны поворот камеры, движение вдоль берега, размещение/разрушение блоков у воды, смерть и повторный вход в мир. Рендер остаётся 100% по умолчанию; уже выбранные пользователем параметры не сбрасываются.

В `/switch/lucid-blocks/boot.log` должны появиться:

```text
[lucid-nx] NSP02 OPT05 RU: required voxel classes present
[nx-locale] Russian messages loaded: 797
[nx-water] samples=...
```

Полный NSP содержит движок и игровые ресурсы. Если запускать прежний установленный NSP, он продолжит использовать свой встроенный пакет, даже когда файлы для hbmenu на SD обновлены. Поэтому для этого прогона нужно установить именно NSP02.

Запись файлов на карту не означает установки NSP или проверки игры на консоли. Копии проверяются SHA-256; реальные FPS и стабильность оцениваются после запуска на Switch.
